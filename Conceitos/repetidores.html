Repetidores e Loops

Repetições me Java Script são baseicamente 2:

While

Declaração de variaveis:


var contador = 1


while (contador <= 5) {

console.log('Hellow, World')

contador++

}


**Esse scrip repete a mensagem no console 5 vezes até o contador ENQUNATO ele for menor ou igual 5.

Do while

Declaração de variaveis:


var contador2 = 1


do {

console.log('Hellow, World')

contador2++

} while (contador2 <= 5)


**Esse script executa ação e DEPOIS acrescenta +1 ao contador e repete ENQUANTO ele for menor ou igual a 5.
