Operadores Js

Soma: +
Subtração: -
Multiplicaçao: *
Divisão: /
Resto da D: %
Potenciação: **


Operadores de Atribuição

var n = 3

n = n + 4 ---> n += 4
n = n - 5 ---> n -= 5
n = n * 4 ---> n *= 4
n = n / 2 ---> n /= 2
n = n ** 2 ---> n **= 2
n = n % 5 ---> n %= 5

Operadores de Incremento

var n2 = 10

  • Pré-incremento ++n2
  • Pós-incremento n2++
  • Pré-decrimento --n2
  • Pós-decrimento n2--
